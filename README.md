# Studio Full — расширение Studio Lite

Это **самостоятельная реконструкция** функций по видео-референсам, а не исходная полная версия автора: по готовому видео нельзя восстановить точный код, модели и анимации. За основу взят присланный Studio Lite; его формат `episode.mjs` и тестовая серия сохранены.

Движок собирает вертикальные 3D-видео по сценарию: персонажи, камеры, реплики, субтитры, звук и MP4. В дополнение к Lite здесь есть:

- необязательный яркий игрушечный стиль: скруглённые блочные персонажи с мимикой, жестами, предметами в руках и уютная кухня;
- три процедурные локации по мотивам видео: аэродром, ангар и убежище;
- импорт локальных GLB-персонажей со скелетом и клипами анимации, а также двух примеров моделей Quaternius;
- локальный статический GLB-реквизит и телевизор со статикой или заранее подготовленной видеозаписью;
- дополнительные стилизованные эффекты крови, ран и отделения частей тела;
- пространственное **стерео**: панорама и громкость зависят от камеры и положения источника;
- примеры и проверки. `renders/demo_zone.mp4` — уже готовое короткое видео-пример.

## 1. Запуск

Нужен компьютер с **Node.js 18+**, интернет при первой установке и около 2 ГБ свободной оперативной памяти. Это проект для Windows, Linux или macOS, а не приложение для телефона. Зависимости загружают three.js, Chromium и ffmpeg.

1. Распакуйте архив в отдельную папку.
2. Установите Node.js с https://nodejs.org/.
3. Откройте терминал **в папке с `studio.js`**.
4. Установите зависимости:
   - Windows: запустите `setup.bat` или выполните `npm install`.
   - Linux/macOS: `bash setup.sh`.
5. Посмотрите готовый файл `renders/demo_zone.mp4`, либо создайте новый:

```bash
node studio.js build demo_zone
node studio.js preview demo_zone shots --res 270x480 --out 270x480
node studio.js render demo_zone --res 540x960 --out 540x960 --fps 12 --interp 24
```

Кадры предпросмотра лежат в `work/demo_zone/preview/`, готовый ролик — в `renders/demo_zone.mp4`. Рендер может занимать минуты: 3D-кадры рассчитываются в Chromium. На слабом ПК начните с `--res 270x480 --out 270x480 --fps 8 --noaa --noshadow`.

На Windows можно запустить `render.bat demo_zone --res 540x960 --out 540x960 --fps 12 --interp 24`, а на Linux/macOS — `bash render.sh demo_zone ...`. Эти скрипты пытаются продолжить прерванный рендер. Изменение сценария, параметров, кода или файлов ресурсов сбрасывает старые куски.

В Linux при сообщении о недостающих библиотеках Chromium установите системные зависимости Puppeteer. Для Debian/Ubuntu обычно нужны `libnspr4`, `libnss3`, `libatk1.0-0`, `libatk-bridge2.0-0`, `libcups2`, `libxkbcommon0`, `libxdamage1`, `libgbm1`, `libxcomposite1`, `libxrandr2`, `libpango-1.0-0`, `libcairo2` и пакет `libasound2` либо `libasound2t64` (имя зависит от версии системы).

## 2. Примеры

| Серия | Что показывает |
|---|---|
| `test_pult` | Исходная серия Lite с озвучкой. |
| `demo_toy` | Игрушечные персонажи, кухня, разговор, очки, фартук, холодильник, печенье, пульт и растущая стопка тарелок. Готовое видео: `renders/demo_toy.mp4`. |
| `demo_zone` | Три новые локации, анимированная GLB-модель, движение камеры, огонь и пространственное стерео. |
| `demo_fx` | Стилизованные органы и отделение конечностей у блочной и GLB-модели. Содержит мультяшную жестокость. |
| `demo_media` | Внешняя статическая GLB-модель и телевизор со статикой. |

В `demo_toy` для новых персонажей использованы три TTS-реплики из присланной серии `test_pult` и музыка из проекта; голоса даны только как пример. В `demo_zone` реплика показана **только субтитрами** — озвучка к этому примеру не приложена. Музыка и эффекты звучат. Исходная `test_pult` содержит голосовые файлы.

## 3. Своя серия и озвучка

Скопируйте `episodes/demo_zone` в `episodes/my_episode`, затем измените `episode.mjs`. Для списка реплик:

```bash
node studio.js voice-script my_episode
```

Запишите каждую реплику в `episodes/my_episode/voice/<id>/1.mp3`, `2.mp3` и т. д. Номера идут по порядку реплик конкретного персонажа. Затем:

```bash
node studio.js prep my_episode
node studio.js build my_episode
node studio.js preview my_episode shots
node studio.js render my_episode --res 540x960 --out 540x960 --fps 12
```

Без Whisper слова внутри реплики распределяются приблизительно, но границы отдельных клипов сохраняются. Для более точной разметки можно установить Whisper командой `bash setup.sh --whisper`. Если текст или озвучка изменились, удалите `episodes/my_episode/voice/words.json`, склеенные `voice/<id>.mp3` и `work/my_episode/align.json`, затем повторите `prep`.

Полный исходный справочник команд Lite — в `README_LITE_ORIGINAL.md`. Его замечание «в Lite нет ...» описывает исходное состояние и не относится к дополнениям ниже.

## 4. Игрушечные персонажи и кухня

Режим `toy` добавлен в тот же движок: прежние персонажи и сценарии не меняются. Он создаёт свои скруглённые модели и декорации по общим признакам референса; это **не точная копия** персонажей, сцены или анимаций из YouTube. Оригинальный ролик и его звук в проект не включены.

Посмотреть пример и собрать его заново:

```bash
node studio.js build demo_toy
node studio.js preview demo_toy shots --res 360x640 --out 360x640
node studio.js render demo_toy --res 360x640 --out 360x640 --fps 24 --noaa --noshadow
```

Готовый файл находится в `renders/demo_toy.mp4`. На слабом компьютере уменьшите до `--res 270x480 --out 270x480 --fps 12`. Например, скопируйте `episodes/demo_toy` в `episodes/my_toy` и измените `episode.mjs`; старые серии при этом останутся на месте. Для новой истории удалите в копии старую папку `voice/` или замените примерные записи своими, иначе останутся реплики про пульт.

### Свой персонаж

В верхнем `cast` добавьте `style: 'toy'`. Цвета задаются обычными CSS-значениями, а масштаб — тройкой чисел:

```js
cast: {
  boy: { style: 'toy', skin: '#ffd62c', hair: '#704529', hairStyle: 'short',
         shirt: '#4896e8', pants: '#79c94f', scale: [.85,.85,.85] },
  grandma: { style: 'toy', skin: '#ffdb61', hair: '#e9e7e3', hairStyle: 'bun',
             shirt: '#bc99da', pants: '#a47bc1', apron: true,
             face: { glasses: true } },
},
```

Причёски: `short`, `long`, `ponytail`, `bun`, `none` или `bald`. Для лица можно включить `glasses`, `lashes`, `blush`; цвет оправы — `face.glassesColor`. Чтобы фартук появился в кадре, у персонажа должны быть **и** `apron: true` в верхнем `cast`, **и** `apron: true` в `cast` конкретной сцены. Старые персонажи без `style: 'toy'` могут находиться с игрушечными в одной сцене.

### Локация, предметы и действия

Используйте `set: 'toy_kitchen'`, `light: 'toyDay'`. Якоря: `kid`, `parent`, `grandma`, `fridge`, `table`, `stove`, `center`. Камеры: `wide`, `table`, `fridge`, `window` и обычные камеры `close`/`medium` с `who`. Объекты локации: `fridge`, `fridgeDoor`, `table`, `tableFood`, `plateStack`, `cabinet`. Пример сцены после объявления персонажей:

```js
scenes: [{
  set: 'toy_kitchen', light: 'toyDay',
  cast: {
    boy: { at: 'kid', look: 'none' },
    grandma: { at: 'grandma', apron: true, look: 'none' },
  },
  beats: [{ dur: 4, cam: 'wide', do: [
    ['set', 'val', { prop: 'fridgeDoor', key: 'open', to: 1, dur: .7 }, 0],
    ['set', 'val', { prop: 'plateStack', key: 'height', to: 12, dur: 2 }, .8],
    ['boy', 'hold', { R: 'toyCookie' }, .4],
    ['boy', 'pose', 'taste', .7],
    ['boy', 'expr', 'delighted', 1],
    ['grandma', 'pose', 'guard', 1.5],
    ['grandma', 'expr', 'stern', 1.5],
  ] }],
}],
```

`fridgeDoor.open` принимает значения от `0` (закрыт) до `1` (открыт); `plateStack.height` — от `0` до `12`, промежуточные значения анимируют рост. Доступны обычные `show`, `hide`, `move`, `walk`, переключение камер и другие команды движка. Предметы для `hold`: `toyPlate`, `toyPie`, `toyCookie`, `toySpoon`, `toySalad`, `toyRemote`; убрать предмет — `{ R: null }` или `{ L: null }`.

Новые позы: `toyTalk`, `toyReach`, `taste`, `guard`, `excited`, `dizzy`. Новые выражения: `delighted` (радость и щёки), `stern` (строгость), `dizzy` (спиральные глаза). Работают и прежние выражения, например `happy`, `shocked`, `suspicious`. У персонажей нет автоматического физического захвата или сложного покадрового рига пальцев: жесты и перенос предмета задаются командами.

Для речи положите свои записи в `voice/<id>/1.mp3`, `2.mp3` и выполните `prep`, как в разделе 3. Рот приблизительно следует **громкости** голоса, а не фонемам. Если реплика задана без записи, рот имитирует разговор, но аудио автоматически не создаётся. Исправлена обработка звуковой огибающей при подготовке, поэтому после обновления старой серии заново выполните `node studio.js prep <имя_серии>`.

## 6. GLB-персонажи и анимация

Добавьте персонажу свойство `skinned`:

```js
cast: {
  monster: {
    zombie: true, shirt: '#555', pants: '#333', hairStyle: 'none',
    skinned: { src: 'zombie_male', height: 5.3 }
  }
}
```

`zombie_male` и `soldier_male` уже приложены в `assets/models/skinned/`. Это стилизованные модели, не оригинальные монстры из видео. Для своей модели поместите, например, `creature.glb` в `assets/models/skinned/` и укажите `src: 'creature'`. Модель должна быть glTF/GLB с совместимым скелетом; FBX сначала нужно преобразовать в GLB, например в Blender. `height` — желаемый рост в единицах Studio (рост блочного персонажа примерно 5.3). Направление можно поправить через `yaw: Math.PI`.

Посмотреть имена костей и встроенных клипов:

```bash
node tools/model-info.mjs assets/models/skinned/zombie_male.glb
```

Движок автоматически выбирает `Idle`, `Walk` и `Run` во время обычной стойки и `walk`. Можно явно управлять клипом из `do`:

```js
['monster', 'mocap', 'Walk', 0],
['monster', 'mocap', { clip: 'Punch', speed: 1, loop: false }, 2],
['monster', 'mocap', false, 3.5], // снова автоматический выбор
```

Клипы из отдельного файла: `skinned: { src: 'creature', mocapFile: 'walks.glb' }`, файл — в `assets/mocap/`. Кости в клипах должны иметь **те же имена**, что и в модели. Если имена клипов совпадают, внешний файл имеет приоритет. Для других названий стандартных клипов можно задать `clipMap: { idle: 'Idle_01', walk: 'Walk_Forward', run: 'Run_Forward' }` внутри `skinned`.

Ограничения: автоматического ретаргетинга произвольных скелетов, импорта FBX, полноценного лицевого рига и привязки предметов к рукам GLB-модели нет. Физический рэгдолл и процедурная мимика исходного Lite работают для блочного персонажа; на произвольную GLB-модель они не переносятся автоматически. Подбирайте модели и анимации совместимо и проверяйте их права.

## 7. Эффекты

Примеры в массиве `do`:

```js
['monster', 'gut', { dur: .8 }, 0],
['monster', 'dismember', { part: 'armR', spray: true, bleed: 3 }, 1],
['set', 'blood', { kind: 'pool', at: [0, 0, 0], r: 1.2 }, 1],
['set', 'fire', { at: [2, 0, -4], scale: .8, for: 3, smoke: true }, 0],
```

Для блочных персонажей поддерживаются `head`, `armL`, `armR`, `legL`, `legR`; для GLB в зависимости от костей дополнительно доступны `forearmL/R`, `handL/R`, `shinL/R`. Кости с общими именами определяются автоматически. Для необычных имён можно передать `skinned.bones`, например `{ LeftArm: 'UpperArm_L' }`.

Эффекты процедурные и приблизительные: отделение GLB-конечности выбирает треугольники по весам костей, поэтому качество зависит от модели и срез может быть незамкнутым. Они не восстанавливают оригинальные ресурсы из видео. Проверочный сценарий — `demo_fx`.

## 8. Пространственный звук

Включите в серии:

```js
spatial: { interval: .25, near: 8, rolloff: .25, minGain: .25, pan: .85 },
```

И привяжите эффект к персонажу, якорю или координатам:

```js
['sfx', 'step', { at: 'monster', vol: .7 }, 0],
['sfx', 'metal', { at: 'barrels', vol: .7 }, 1],
['sfx', 'thud', { at: [3, 0, -5], vol: .8 }, 2],
```

Движок сэмплирует положение камеры и источника, плавно меняет левый/правый канал и ослабляет звук с расстоянием. Реплика с голосовым файлом по умолчанию следует за персонажем, а narrator и звуки без `at` остаются обычным стерео. `flat: true` в параметрах эффекта отключает позиционирование. Это **стереопанорама, не HRTF и не полноценная акустическая симуляция**; отражения и препятствия не рассчитываются. Звук отдельно: `node studio.js audio demo_zone`.

## 9. Свой статический реквизит и телевизор

Положите GLB в `assets/props/` и объявите в сцене:

```js
models: [
  { id: 'crate', src: 'crate.glb', at: [3, 0, -5], scale: 1, rot: 0 }
],
```

Можно задать и путь внутри проекта, как в `demo_media`: `src: 'assets/models/blocky/character-a.glb'`. Имя `id` используется для `['set', 'hide', 'crate', 0]`, `show`, `move` и `shake`. Импорт предназначен для **статического** реквизита; для движения персонажей используйте `skinned`. Масштаб модели по умолчанию: один метр GLB ≈ 3.2 единицы Studio.

Процедурный телевизор добавляется через `tvs`:

```js
tvs: [{ id: 'crt', at: [-4, 0, -4], scale: 2, light: 4 }],
// внутри do:
['set', 'tv', { id: 'crt', mode: 'on' }, 0],
```

В режиме `on` появляется статика. Для записи заранее сохраните JPEG-кадры `f0000.jpg`, `f0001.jpg` ... в папку проекта (например, командой `node studio.js frames test_pult --fps 8 --res 320x240 --out 320x240 --dir assets/feeds/tape`). Добавьте на уровень серии `feeds: [{ id: 'tape', dir: 'assets/feeds/tape', fps: 8 }]`, в телевизор `feed: 'tape'` и действие `['set','tv',{ id:'crt', mode:'tape' },1]`. Звук записи при необходимости добавляется отдельно.

После установки зависимостей:

